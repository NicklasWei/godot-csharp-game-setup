# __TITLE__ developer wiki

The developer reference for __TITLE__, built from the repository itself, so it can't drift from the game.

- **[Reference](generated/reference/content/index.md)**: every content kind and definition, every tuning record,
  the glossary of Core enums, the controls, the dev flags, and the localization status. These pages are generated by
  `tools/__GAME__.Wiki`: it loads `content/` with Core's own `ContentLoader`, reads the code-held tuning records
  (`…Settings`) and enums by reflection, takes descriptions from Core's XML docs, bindings from `project.godot`, and
  strings from `localization/`.
- **[Design docs](../../docs/GDD.md)**: the GDD, art direction, coding standards, implementation plan, and every
  architecture decision record, read in place from `docs/`.
- **[Core API](generated/api/toc.yml)**: the Core reference, built from the assembly and its XML docs.
- **[Project overview](../../CLAUDE.md)**: the stack, commands, and rules.

To change what a page says, change its source (content JSON, a PO string, a settings record, a doc comment, the input
map, or a doc in `docs/`) and rebuild. Generated pages are never committed. See
[ADR 0008](../../docs/adr/0008-developer-wiki.md) for how the wiki is built and why it never touches the game.

## Building it locally

```bash
dotnet tool restore
```
```powershell
./tools/wiki/build.ps1 -Serve
```

The script builds the generator, writes the pages, and runs DocFX. `-Serve` then serves the site at
<http://localhost:8080>. On Linux or macOS, run `tools/wiki/build.sh --serve`.
