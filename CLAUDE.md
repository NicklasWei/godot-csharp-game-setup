# CLAUDE.md

This repository is the **godot-csharp-game-setup** skill: `SKILL.md`, `references/`, `scripts/`, and the project
template in `templates/project/`. These rules are for working on this repository. They are not part of the template:
never copy them into `templates/project/` or into a scaffolded project.

## Strict rules

- **Never name or identify another repository or project.** The games this skill learns from may be under NDA. In
  files, commit messages, pull request titles and descriptions, and review replies, refer to them only in anonymized,
  general terms, such as "a game built with this template" or "the source project". Leave out titles, code names,
  repository names, studios, people, and anything else that identifies them, such as their lexicon, features, or
  story. When a change needs context, describe the general problem and the fix.
- **Keep the skill current the way `SKILL.md` describes** (its "Keeping this skill current" section): template files
  never start with a dot, `templates/MANIFEST.txt` lists every template file, and a throwaway scaffold verifies any
  change to the template.
